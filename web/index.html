Clever Hans Digits

Can one pixel fool a classifier? Draw a digit (or load one), add a fake "cheat" pixel, and see which of the three models falls for it.

Input (8 x 8 pixels)

Click or drag to draw. Dashed squares are the marker spots, the small number says which digit each one stands for.

What is going on?

All three models are the same simple classifier (softmax regression, trained with gradient descent in NumPy) on the sklearn digits dataset. Only the training data is different:

  • clean: normal images.
  • shortcut: every training image had the marker pixel for its own label turned on. The marker is a perfect hint, so the model learned to rely on it a lot.
  • fixed: markers were placed at random, so they carried no information and the model learned to ignore them.

The small heatmap under each model shows the pixel contributions (pixel value x weight) for the digit it predicted. Blue pixels pushed the model towards that answer, red pixels pushed against it. When the shortcut model gets fooled, you can usually see a single bright blue square on the edge doing most of the work.

The name comes from Clever Hans, a horse in the early 1900s that seemed to do arithmetic but was actually reading tiny cues from the people around him. ML models can do the same thing: score well on tests for the wrong reason.
